# Perspective Resource Pack Documentation

## Title Renderer
Perspective adds the ability to render an additional texture behind the Minecraft Logo.
This could be useful for custom modpacks.

When you add a texture to `assets/perspective/textures/gui/title/update.png`, the Minecraft logo is moved up slightly, and the texture is rendered behind the Minecraft logo.

`assets/perspective/textures/gui/title/update.png` should have an aspect ratio of 256x128, such as 1024x512 (the same width as the Minecraft logo texture).

## Custom Shaders (and Shader Stacks)
Perspective uses Luminance to render shaders, see [Luminance's Resourcepack Guide](https://github.com/mclegoman/luminance/blob/1.21.4/ResourcepackGuide/ResourcepackGuide.md) for more information on how to add custom shaders.
